## Bugs and fixes (branch `fix/live-test`)

1. **Native `confirm()` / `prompt()` block the page** (Drafts delete, bulk delete, Library From URL / New folder /
   delete, Ideas new group, channel Clear all / Disconnect, App keys remove, "publish anyway" overrides).
   Repro: Publish → Drafts → Delete post → page frozen for an automated browser; From URL in Library likewise.
   Fix: promise-based in-app dialog (`confirmAsync` / `promptAsync` + `<AskHost/>` in `web/src/ui.jsx`,
   `data-testid="ask"`, `ask-input`, `ask-ok`, `ask-cancel`); all call sites switched. E2E helper `ask_ok(page)`.
2. **Community empty without explanation.** Instagram connector now compares `comments_count` with what `/comments`
   returns; if Meta withholds them it stores `meta.comments_note`, logs one warning event, `/api/comments/sync`
   returns `notes`, `/api/channels` exposes `comments_note`, and Community shows an amber banner.
3. **Composer always pre-selected the first channel (YouTube).** Now remembers the last channels used
   (`localStorage huhq-last-channels`).
4. **No Carousel in the Instagram type switch.** Switch is now Post / Carousel / Reel / Story.
5. **No alt text in the Composer.** Instagram section lists attached images with an alt-text field; saved on the
   media file (`PATCH /api/media/{id}`) and sent as `alt_text` at publish.
6. **Stale follower count** — covered by main's daily profile/follower snapshot (`c7b0106`); no extra change.

Not bugs: Upload button opens a hidden file input (works for people, invisible to the automation); per-post insights
empty because nothing has been published through HuhQueue yet; the "HuhByte AI" logo alt is the brand avatar.

Cleanup: the three `QA TEST - delete` drafts were deleted server-side with `posts.delete_target`; none remain.
