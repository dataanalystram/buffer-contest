      Use HuhQueue from the assistant you already pay for. Every app reaches the same tools at one address, and every post it makes waits in your Inbox until you approve it.
      
        
      
          
      Your MCP address
      
          
          
      Apps that sign in with OAuth (Claude, ChatGPT) only need this address. Others use it with an agent token you create here. Read the agent guide
      
        
      
        
      
        
      Tokens follow the rules on the Agents screen: approval by default, a daily cap, and one kill switch for all of them.
