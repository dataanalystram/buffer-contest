What happens between the link and your queue

One post per channel

X, LinkedIn, Instagram, Threads, Bluesky and Mastodon each get their own wording and length. Long reads become threads where the network supports them.

You read it before it ships

Each draft is previewed the way its network shows it. Edit in place, then send one or all of them to Buffer as a draft, the next slot or a set time.

Your Buffer, unchanged

Channels, queue and ideas come straight from your Buffer account. HuhQueue adds the writing and the review step, nothing else.

Counted the way Buffer counts

A caption that fits in a text box can still be rejected by the network. HuhQueue measures every draft with the same rules Buffer applies, so a post that leaves here is a post that sends.

Agents draft. You decide.

Claude, ChatGPT or Cursor connect over MCP and write posts for your channels. Their posts wait in your approvals until you read them.

  • Approval by default, Buffer drafts only, or trusted to schedule. You pick per agent.
  • A daily cap on every agent token.
  • One switch that stops every agent at once, and a log of everything they did.
Add it to Claude Code 
claude mcp add --transport http huhqueue \
  https://huhqueue-studio.onrender.com/mcp \
  --header "Authorization: Bearer hq_YOUR_TOKEN"
Plain REST works too. The endpoints the interface uses accept the same token.
