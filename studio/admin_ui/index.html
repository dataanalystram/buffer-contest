Delete this user?

This erases every row, file and token the account has, and can't be undone. Only a hashed id, the time and your id are kept.

Block this user?

Their sessions end now, their agents and MCP apps stop, and they can't sign in until you unblock them. Nothing is deleted.

Agent and MCP tokens

An hourly cap counts every request on the token, reads included (empty: no cap). The daily cap counts actions (1 to 100). Revoke ends the token for good; to pause a whole account, block it instead.
